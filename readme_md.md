# REC Genesis Audit

**RL-среда, генератор синтетических компаний и бенчмарк для обучения автономных ИИ-аудиторов финансовой отчётности.**  
Проект разработан в рамках **GENESIS.EXE Hackathon 2026 (FinTech)**.

---

## О проекте

Ручной финансовый аудит дорог и обычно охватывает лишь малую выборку документов, из-за чего сложные схемы (дробление счетов, подмена валютных курсов, фиктивные контрагенты) остаются незамеченными.

**REC Genesis Audit** решает эту проблему, предоставляя полностью воспроизводимую, офлайн-готовую RL-среду (`AuditEnv`), в которой ИИ-агент пошагово исследует бухгалтерские реестры, проверяет первичные документы, выполняет точные вычисления и сдаёт структурированный отчёт о найденных нарушениях.

### Ключевые особенности
* **Строгая изоляция `truth.json`:** агент не имеет доступа к эталонным ответам во время прохождения эпизода.
* **Безопасные инструменты:** `list_records`, `get_document`, `get_policy`, безопасный AST-калькулятор на базе `Decimal` (`calculator`) и `submit`.
* **Защита от читерства (Anti-Cheat):** оценщик начисляет жёсткий штраф (`-1.000`) за массовую пометку документов наугад (`attack_mark_all`) и штрафует за лишние шаги и ложные срабатывания.
* **Ограничения среды:** тайм-аут эпизода — 60 секунд, лимит — 100 шагов.
* **Нулевые бинарные зависимости:** схемы данных в `src/schemas.py` реализованы на чистом Python (`dataclasses`), что гарантирует стабильный запуск на Windows, macOS и Linux без проблем с компиляцией и системными политиками безопасности.

## Результаты бенчмарка

Прогон 4 базовых политик на **5 сгенерированных эпизодах** (`seeds = [101..105]`, по 25 базовых счетов в каждом, режим `full`):

| Policy | Avg F1 | Avg Precision | Avg Recall | Avg Reward | Avg Steps |
| :--- | :---: | :---: | :---: | :---: | :---: |
| `random` | 0.000 | 0.000 | 0.000 | -1.000 | 6.0 |
| `rule_based` | 0.278 | 0.314 | 0.250 | -0.453 | 5.4 |
| `attack_mark_all` | 0.000 | 0.000 | 0.000 | -1.000 | 2.0 |
| `oracle` | 1.000 | 1.000 | 1.000 | +1.000 | 1.0 |

**Выводы по метрикам:**
* `oracle` достигает `F1 = 1.000` и `Reward = +1.000` — задачи полностью решаемы, а оценщик корректен.
* `rule_based` уверенно обходит случайную политику (`F1 = 0.278`), но оставляет большой запас до потолка, подтверждая нетривиальность среды для обучения RL/LLM-агентов.
* `attack_mark_all` получает максимальный штраф `-1.000`, доказывая устойчивость метрики к взлому награды.

## Быстрый старт

### Локальный запуск (Python 3.10+)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/abylaichik0w0/rec-genesis-audit.git
cd rec-genesis-audit

# 2. (Опционально) создать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. Запустить генерацию эпизодов, оценку всех 4 политик и экспорт траекторий
python -m scripts.run_eval
```

Скрипт сгенерирует 5 реальных эпизодов в `data/eval_episodes/`, выведет таблицу метрик в консоль и сохранит траектории для визуализации в `artifacts/trajectories.jsonl`.

### Запуск тестов

```bash
pytest
```

### Запуск через Docker (Offline-ready)

```bash
docker build -t rec-genesis-audit .
docker run --rm rec-genesis-audit
```

## Интерактивный плеер траекторий (`Audit Replay`)

В проекте есть локальный веб-плеер **Audit Replay.EXE**, который работает полностью в браузере (без бэкенда и отправки данных в сеть) и поддерживает два режима: **«Понятный вид»** (для бухгалтеров и жюри) и **«Сырой JSON»** (для разработчиков).

1. Откройте файл `demo_ui/index.html` в любом современном браузере.
2. Нажмите кнопку **«↑ Загрузить .jsonl»** и выберите любой файл траекторий из папки `artifacts/`:
   * `artifacts/trajectories.jsonl` — реальные траектории 4 политик после запуска `scripts/run_eval.py`.
   * `artifacts/hard_audit_schemes.jsonl` — сложные многошаговые схемы мошенничества (дробление счетов / смурфинг, завышение курса EUR/USD + фиктивный поставщик, манипуляция закрытием года).
   * `artifacts/tricky_traps_and_attacks.jsonl` — ловушка с законным НДС 20% (чистый аудит), ошибка поспешного агента и блокировка спам-атаки.
