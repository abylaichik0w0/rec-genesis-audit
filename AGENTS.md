# Правила проекта REC Genesis FinTech (Python 3.11)
- Стек ядра: Python 3.11, pydantic>=2.0, pytest. Без интернета, GPU и платных API[cite: 1, 4].
- Деньги: строго int в минимальных единицах (копейки/центы, поля *_minor). Никаких float для денег.
- Курсы валют (FX): строковые десятичные (Decimal).
- Время: ISO-8601 со смещением (например, 2026-11-19T14:00:00+05:00).
- Пустые ссылки: явный None / null[cite: 2].
- Калькулятор: только безопасный AST-парсер для арифметики, никакого eval()[cite: 2].
- Изоляция: файлы truth.json и provenance.json никогда не попадают в наблюдения среды и не импортируются в клиентский код[cite: 2].
- Фронтенд живёт строго в папке demo_ui/, читает готовый trajectories.jsonl и не влияет на Dockerfile[cite: 4, 5].
