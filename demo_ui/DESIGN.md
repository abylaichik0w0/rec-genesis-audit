# DESIGN — REC Genesis Audit Replay

## Назначение

Локальный демонстрационный визуализатор для показа работы агента финансового аудита: действия, ответы среды, ошибки, findings и доступная метрика F1.

## Архитектура

Чистый HTML/CSS/JS. File API читает пользовательский `.jsonl`; каждая непустая строка парсится как JSON, строки группируются по `episode_id`, шаги сортируются по `step`. Встроенный mock содержит 6 шагов: reset → list_records(invoices) → get_document → list_records(payments) → calculator → submit. Состояние проигрывателя хранится в памяти страницы.

## Интерфейс

Тёмная панель с cyan/teal акцентами, статистика сверху, timeline слева, action и observation в двух панелях, транспортные контролы и findings снизу. Адаптивная верстка для узких экранов.

## Корректность данных

Показываем `reward` отдельно от `F1`. F1 отображаем только при наличии явной метрики в дополнительных полях, потому что базовая схема trajectory её не гарантирует. Findings извлекаем из submit. Mock-значения не являются результатом реальной оценки.

## Безопасность и ограничения

Никакого backend, сетевых запросов, eval/exec и внешних зависимостей. Входной JSON выводится через `textContent`, а не как HTML. Нельзя передавать в публичные траектории `truth.json`, `provenance.json`, `seed` или секретные поля. Визуализатор не валидирует финансовые расчёты и не оценивает F1 самостоятельно. При наличии нескольких эпизодов доступен выбор эпизода.

## Демонстрация

Откройте `demo_ui/index.html`, проиграйте встроенные 6 шагов, затем загрузите `artifacts/trajectories.jsonl`. Проверьте навигацию, ошибки JSONL и вывод findings.
